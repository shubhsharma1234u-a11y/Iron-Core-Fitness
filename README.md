# IronCore Fitness

IronCore Fitness is a fictional gym website created as a frontend portfolio and practice project.

## Features

- Responsive design
- Mobile-friendly layout
- Membership pricing plans
- Scroll animations
- Smooth navigation
- Interactive JavaScript buttons
- WhatsApp membership inquiry integration
- Contact form

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Purpose

This project was created to practice frontend development and demonstrate responsive website design and JavaScript interactivity.

## Disclaimer

IronCore Fitness is a fictional business created for demonstration and portfolio purposes.
